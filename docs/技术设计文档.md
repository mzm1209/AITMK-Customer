# AITMK 客服系统技术设计文档

## 1. 技术目标

一期前端采用静态 Web 方案，直接对接 Spring Boot 后端 REST 与 WebSocket 接口，实现低部署成本、快速上线与可配置接入。

## 2. 技术栈

- HTML5
- CSS3
- 原生 JavaScript
- WebSocket + STOMP
- 浏览器 localStorage

## 3. 前端文件结构

- `index.html`：页面结构与模板。
- `styles.css`：页面样式、布局、会话状态样式。
- `app.js`：登录、接口调用、WebSocket、消息渲染、附件处理逻辑。
- `README.md`：部署、运行、接口与配置说明。

## 4. 核心模块说明

### 4.1 认证模块
- 登录：调用 `/api/auth/login`。
- 登出：调用 `/api/auth/logout`。
- 登录成功后保存 `agentRowId`，作为后续查询与订阅依据。

### 4.2 会话模块
- 获取客户列表：`/api/chat/customers/serving`。
- 获取消息记录：`/api/chat/messages`。
- 会话选中后展示聊天详情并清除红点提醒。

### 4.3 消息发送模块
- 文本发送：`/api/chat/reply`。
- 附件上传：`/api/chat/media/upload`。
- 多媒体发送：`/api/chat/reply/media`。
- 是否允许回复由服务端字段 `canReply`、`within24h`、`serviceStatus` 决定。

### 4.4 实时通信模块
- 握手端点：`/ws`。
- 订阅主题：`/topic/agent/{agentRowId}`。
- 收到 `history` / `new_message` 后更新本地缓存与界面。
- 重连成功后调用 `/api/agent/ws/reconnected`。

### 4.5 配置模块
- `aitmk.apiBaseUrl`：后端服务地址。
- `aitmk.replyFrom`：业务号码 ID。
- 均保存在浏览器 `localStorage` 中。

## 5. 关键实现说明

- 优先使用页面注入的 `SockJS + StompJs`。
- 若外部依赖不存在，则回退到原生 WebSocket + STOMP 解析。
- 客户列表与消息列表均使用前端缓存，减少重复渲染。
- 会话红点提醒通过本地未读标记实现。
- 附件上传前执行扩展名、MIME、文件大小校验。

## 6. 部署方式

- 推荐使用 Nginx 托管静态文件。
- 也支持使用 `http-server` 等轻量静态服务。
- 前后端跨域需由 Spring Boot 侧放行前端访问域名。

## 7. 技术边界

- 当前前端无独立数据库，状态以浏览器内存和本地存储为主。
- 权限、安全审计、消息高级检索等能力暂未在一期实现。
