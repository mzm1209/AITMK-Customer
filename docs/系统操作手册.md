# AITMK 客服系统操作手册

## 1. 登录系统

1. 打开客服工作台地址。
2. 输入用户名和密码。
3. 点击“登录”。

## 2. 查看客户会话

1. 登录成功后，左侧显示客户会话列表。
2. 点击任一客户，可查看右侧历史聊天记录。
3. 若会话有红点，表示收到新的实时消息。

## 3. 发送文本消息

1. 选择客户会话。
2. 在文本框输入回复内容。
3. 点击“发送人工回复”。

> 若会话为只读或服务端判定不可回复，发送按钮会禁用。

## 4. 发送附件消息

1. 选择客户会话。
2. 在“附件类型”中选择图片、视频、音频或文件。
3. 选择本地文件。
4. 如有需要，填写附件说明。
5. 点击“上传并发送附件”。

## 5. 修改系统配置

### 5.1 设置服务地址
1. 点击“服务地址设置”。
2. 输入 Spring Boot 服务地址。
3. 点击“保存”。

### 5.2 设置业务号码
1. 点击“业务号码设置”。
2. 输入业务号码 ID。
3. 点击“保存”。

## 6. 登出系统

1. 点击“登出”。
2. 系统退出当前坐席登录状态。

## 7. 常见说明

- 页面请通过 `http://` 或 `https://` 访问，不要直接双击 `index.html`。
- 若无法请求后端，请检查服务地址与 CORS 配置。
- 若无法发送附件，请检查文件格式与大小是否符合要求。
